# 🎵 Music Player

A simple and interactive **Music Player** built using **Python**, **Tkinter**, and **Pygame**. This desktop application allows users to load music from a folder, browse songs, and control playback through a clean graphical interface.

---

## ✨ Features

* 📂 Load music from any folder
* 🎵 Display songs in a playlist
* ▶️ Play selected songs
* ⏸️ Pause and resume playback
* ⏹️ Stop music
* ⏭️ Play the next song
* ⏮️ Play the previous song
* 🖥️ Simple and easy-to-use interface

---

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* Pygame (Audio Playback)
* OS Module (File Management)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ASHISH704504/music-player.git
```

### 2. Navigate to the project directory

```bash
cd "Music Player"
```

### 3. Install the required dependency

```bash
pip install pygame
```

### 4. Run the application

```bash
python main.py
```

---

## 🎮 How to Use

1. Run the application.
2. Click **Load Music**.
3. Select the folder containing your music files.
4. Choose a song from the playlist.
5. Use the playback controls to:

   * ▶️ Play
   * ⏸️ Pause / Resume
   * ⏹️ Stop
   * ⏮️ Previous
   * ⏭️ Next
